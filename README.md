## 🔒 About Blind Drop X

**Blind Drop X** is an ultra-secure, zero-knowledge ephemeral messaging platform built for high-stakes, volatile communications.

* 📵 **Native Anti-Screenshot Shield:** Enforces hardware-level `FLAG_SECURE` on Android and 3-finger swipe gesture blackout shutters.
* 🎙️ **Listen-Once Voice Notes:** Senders can replay freely; recipients are limited to strictly 1 playback before permanent memory destruction.
* 👁️ **View-Once Image Sharing:** Real-time client-side compressed images destroyed immediately upon closing.
* ⏳ **Volatile Auto-Destruct Timers:** Rooms self-destruct (1 to 60 min) with zero database persistence — 100% in-memory RAM.
* 🔐 **Client-Side XOR + SHA-256:** End-to-end encryption with room password-derived keys.
* 👻 **Anonymous Volatile Codenames:** Zero accounts, no emails, no phone numbers required.

## 📱 Android APK Installation Guide

1. Download the APK directly from [Blind Drop X Promo](https://blind-drop-x-promo.vercel.app/downloads/BlindDropX-v2.0.0.apk).
2. Tap the downloaded `.apk` file on your Android device.
3. If prompted, enable **"Install from unknown sources"** for your browser in Android Settings.
4. Open **Blind Drop X**, choose your session lifetime, create or join a room, and communicate securely.
